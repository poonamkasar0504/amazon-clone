# Amazon Clone Website

## About the Project

This is a frontend Amazon Clone website created using HTML and CSS.

The main purpose of this project is to practice frontend web development concepts such as HTML structure, CSS styling, Flexbox, navigation bars, search bars, product sections, and footer design.

The website is designed similar to the Amazon homepage.

## Technologies Used

- HTML5
- CSS3
- Font Awesome
- Flexbox

## Features

- Amazon-style navigation bar
- Amazon logo section
- Delivery location section
- Search bar with category selection
- Account & Lists section
- Returns & Orders section
- Shopping Cart section
- Navigation panel
- Today's Deals section
- Customer Service section
- Registry section
- Gift Cards section
- Sell section
- Hero banner section
- Health & Personal Care category
- Clothes category
- Furniture category
- Electronics category
- Beauty Picks category
- Pet Care category
- New Arrivals in Toys
- Fashion Trends section
- Back to Top section
- Footer with multiple information sections
- Amazon-style copyright section
